# Inventory for iOS (native)

A native Swift 6 / SwiftUI rewrite of the Inventory app for iOS 26 and later. It ships as an update to the React Native app (same bundle id, `com.wystudio.inventory`) and adopts the data the React Native build left on the device.

Once the native app ships, the React Native app is removed, and with it the Android app and the RN web build. The backends stay as they are, and the home server keeps running the shared TypeScript data layer (`src/core`, `src/db`, `src/repositories`) and its desk page, so household mode and household imports keep exact parity with that code. See `docs/spec/DECISIONS.md`.

- `App/` holds the SwiftUI app target: views, navigation and resources.
- `Packages/InventoryKit/` holds the logic (storage, networking, services, app models), tested with `swift test`. `InventoryTestSupport` there is a test-only library (a manual clock, temporary directories and defaults suites, a telemetry recorder and a URLProtocol stub server) that every test target uses.
- `Config/` holds the build configurations; see `Config/README.md` for secrets.
- `docs/spec/` holds the porting specs. Start at `00-index.md` and `DECISIONS.md`.
- `docs/CONVENTIONS.md` covers how to build, test and contribute.

The Xcode project is generated by XcodeGen from `project.yml`:

```sh
scripts/mac.sh build      # build for the simulator on the Mac
scripts/mac.sh test       # run the package tests
scripts/mac.sh apptest    # run the app-hosted tests on the simulator
```
