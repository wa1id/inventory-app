## Implementation-level defaults

- Project generated by **XcodeGen** from `native-ios/project.yml`; the `.xcodeproj` is gitignored and regenerated.
- Logic lives in the local SwiftPM package `native-ios/Packages/InventoryKit`, with platforms `.iOS(.v26)` and `.macOS(.v15)` so that `swift test` runs on the build Mac (macOS 15.7) without a simulator. Code that needs UIKit, AVFoundation capture, VisionKit or SwiftUI goes in the app target, or behind `#if canImport(UIKit)`.
- Dependencies (SwiftPM): GRDB 7 (system SQLite; no `DatabaseMigrator`); a WebP encoder (libwebp via `SDWebImageWebPCoder`, or a libwebp SwiftPM package) for photo encoding.
- Swift Testing (`import Testing`) for all new tests.
