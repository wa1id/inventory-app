Fixtures for the image store tests (`Tests/InventoryServicesTests/Images`).

| File | Contents |
| --- | --- |
| `scale-to-fit.json` | `scaleToFit` vectors and the four sizing constants, generated by running the real `src/services/capture/imageScaling.ts`. Regenerate with `generator/scale-to-fit-vectors.test.ts` (its header has the commands); do not edit by hand. |
| `gps-orientation-6.jpg` | A camera-style JPEG: 1600×1200 stored pixels with EXIF orientation 6 (shown 1200×1600), mid-grey with a red block in the stored top-left corner (shown top-right), and GPS, EXIF and TIFF metadata. Used to prove that stored photos carry no metadata and have the orientation baked in. |

Every other test image is drawn at run time with CoreGraphics and encoded with ImageIO.

`gps-orientation-6.jpg` was written on macOS 15 with ImageIO by this script
(`xcrun swiftc -swift-version 6 make.swift -o make && ./make gps-orientation-6.jpg`):

```swift
import CoreGraphics
import Foundation
import ImageIO
import UniformTypeIdentifiers

let width = 1600, height = 1200
let space = CGColorSpace(name: CGColorSpace.sRGB)!
let context = CGContext(
    data: nil, width: width, height: height, bitsPerComponent: 8, bytesPerRow: 0,
    space: space, bitmapInfo: CGImageAlphaInfo.noneSkipLast.rawValue)!
context.setFillColor(CGColor(srgbRed: 0.5, green: 0.5, blue: 0.5, alpha: 1))
context.fill(CGRect(x: 0, y: 0, width: width, height: height))
context.setFillColor(CGColor(srgbRed: 0.86, green: 0.12, blue: 0.12, alpha: 1))
// CoreGraphics puts the origin bottom-left, so the stored top-left block starts at y = height - 300.
context.fill(CGRect(x: 0, y: height - 300, width: 400, height: 300))
let image = context.makeImage()!

let out = URL(fileURLWithPath: CommandLine.arguments[1])
let destination = CGImageDestinationCreateWithURL(out as CFURL, UTType.jpeg.identifier as CFString, 1, nil)!
let properties: [CFString: Any] = [
    kCGImageDestinationLossyCompressionQuality: 0.9,
    kCGImagePropertyOrientation: 6,
    kCGImagePropertyTIFFDictionary: [
        kCGImagePropertyTIFFMake: "FixtureCam",
        kCGImagePropertyTIFFModel: "GPS-1",
        kCGImagePropertyTIFFOrientation: 6,
    ],
    kCGImagePropertyExifDictionary: [
        kCGImagePropertyExifDateTimeOriginal: "2026:08:03 10:15:00",
        kCGImagePropertyExifLensModel: "Fixture lens 4.2mm f/1.8",
    ],
    kCGImagePropertyGPSDictionary: [
        kCGImagePropertyGPSLatitude: 48.8584,
        kCGImagePropertyGPSLatitudeRef: "N",
        kCGImagePropertyGPSLongitude: 2.2945,
        kCGImagePropertyGPSLongitudeRef: "E",
        kCGImagePropertyGPSAltitude: 35.0,
        kCGImagePropertyGPSAltitudeRef: 0,
    ],
]
CGImageDestinationAddImage(destination, image, properties as CFDictionary)
precondition(CGImageDestinationFinalize(destination))
```
